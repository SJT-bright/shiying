拾影使用说明

让收集、整理和回看，留在同一个工作台。

三步保存

在新建下载粘贴分享，选择画质与目录，点击开始下载。需要登录时，在平台卡片里打开内置网页；登录保留在这台电脑的拾影中。

视频号

视频号分享使用内置腾讯元宝解析。请在元宝网页登录，再回到工作台下载。视频号助手和元宝使用不同登录。

图文与批量

图文预览先保存到临时区域。可以右键复制或确认保存；取消、离页和退出会清理未确认图片。批量队列逐条处理，中断后重新启动时保持暂停，点击开始处理继续。

资料与统计

移除记录保留原文件。收藏夹移动同步磁盘目录，冲突时保留原位置。统计只在手动更新时读取；未公开的数据不会按0显示。

来源与许可

使用固定版本的开源解析模块、yt-dlp、FFmpeg和Electron。安装目录包含许可说明，源码与媒体组件对应源包可在GitHub发行页下载。平台验证由用户在内置网页完成。

Windows 10/11 x64；Mac版本使用独立的原生SwiftUI界面。不同电脑的登录与资料独立保存。
